IPv6 к серверу первым: если у сети есть IPv6, подключение к VPN-серверу начинается по IPv6, а IPv4 подхватывает его за доли секунды. Помогает, когда IPv4-адрес сервера заблокирован. Переключатель в «Настройки» → «Дополнительно», включён по умолчанию
Приложение запоминает, по какому адресу сервер ответил, и не тратит время на неработающий IPv6 при каждом соединении. Hysteria2 при неответе по IPv6 сразу переподключается по IPv4
