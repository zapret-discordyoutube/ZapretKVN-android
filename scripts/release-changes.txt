Новая вкладка «Сервисы» после «Серверы»: для YouTube, Telegram и ИИ-приложений выбирается свой сервер, список компактный, с поиском (бета-переключатель)
Серверы для сервисов берутся из всех профилей и подписок, а не только из активной, в основной список и на вкладку «Серверы» они не попадают
На главной вместо окна выбора серверов сервисов краткая сводка, нажатие открывает вкладку «Сервисы»
Во вкладке «О нас» у каждой ссылки свой логотип: Telegram, GitHub, Git, Google Docs
Операции с профилями не запускаются дважды при быстром повторном нажатии
