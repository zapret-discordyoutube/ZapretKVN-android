IPv6 к серверу первым: если у сети есть IPv6, подключение к серверу идёт сначала по нему. Помогает, когда IPv4-адрес сервера заблокирован. Включено, «Настройки» → «Дополнительно»
Приложение запоминает, по какому адресу сервер ответил, и не ждёт неработающий IPv6 при каждом соединении. Hysteria2 при неответе по IPv6 сразу переходит на IPv4
